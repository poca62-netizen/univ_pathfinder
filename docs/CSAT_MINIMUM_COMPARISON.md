# 모의고사 대비 수능 최저 준비도

2026-11-04 구현. 대학 후보 화면에서 비교할 모의고사를 선택하고 전형·지원조건을 펼쳐 확인한다. 처음에는 최신 연도·월을 선택하며 동일 시기의 기관이 여러 개면 선택 표시를 확인해야 한다. 학과별 기준이 여럿인 전형은 지원할 학과·계열을 직접 선택한다. 관심 분야에서 계열을 추정하지 않는다.

## 지원하는 규칙

- 명시된 영역 중 N개 등급 합, N개 영역 각각의 등급 제한
- 수학·국어·탐구 필수 포함, 한국사·영어의 별도 제한
- 통합사회/통합과학 상위 1과목 또는 두 과목 평균. 평균의 소수점 유지
- 통합사회와 통합과학이 별도로 나열된 기준은 각각의 영역으로 계산
- 제공 자료에 최저 없음으로 명시된 기준

전체 문장을 파싱한다. 미해석 문구를 삭제한 뒤 통과시키지 않는다. 영어 등급 재분류·대체과목·계열별 OR·탐구 과목 수 미기재·주석이 포함된 복합 예외는 원문 확인이 필요하다. 학과별 문장 뒤에 공통 주석이 있으면 주석을 떼어내 별도로 계산하지 않는다. 지원 범위 밖 조건은 수동 확인한다. 제공된 전형계획은 최종 모집요강 대조 전이다.

## 시험과 결과

연도·학년·월·시행기관이 일치하는 시험만 묶으며 여러 시험의 최고 등급을 합치지 않는다. 시행기관 미상은 비교 보류한다. 월 단위 모델이므로 같은 달·기관의 별도 시험을 구분할 일자/회차 필드는 후속이며 같은 영역 중복 시 비교를 막는다. 비교 대상은 2025 고1·2026 고2·2027 고3이다. 이전 수능 체계의 선택탐구를 통합사회·통합과학으로 추정하지 않는다. [교육부의 2028 통합형 수능 안내](https://www.korea.kr/news/policyNewsView.do?newsId=148938778)를 참고했다.

필요한 영역 누락·중복·등급 공란/1~9 밖·조회 실패는 자료 부족이다. 점수·백분위에서 등급을 임의 산출하지 않는다. 유효한 모든 필요 영역이 있을 때 허용 조합을 열거해 가장 유리한 조합을 사용한다. 충족 수준·미달 수준과 선택 영역·등급 합·추가 한국사/영어 제한·개선 폭을 표시한다. 이는 해당 학년 모의고사 대비 참고 결과이며 실제 수능 충족이나 합격을 확정하지 않는다. 학업 비교 약·중·강에 합쳐 합격 확률로 만들지 않는다.

## 확인 표시 저장

지원자격·학교장 추천의 본인 확인만 현재 계정별로 이 브라우저/기기에 저장한다. 다른 기기에는 동기화되지 않으며 브라우저 데이터 삭제 시 사라진다. 비로그인 체험은 화면 내 임시 상태다. 성적·생기부 원문을 이 저장소에 복제하지 않는다. 전형명·학과·지원자격·추천·수능 최저 원문이 바뀌면 기존 표시를 재사용하지 않는다. 복원 실패 시 덮어쓰기를 막고 다시 불러오기를 제공하며 저장 실패는 성공 표시하지 않는다.

저장은 [Flutter SharedPreferencesAsync](https://pub.dev/packages/shared_preferences)를 사용한다. DB 마이그레이션은 없으며 공적 자격 인증·추천 확정 정보가 아닌 편의용 표시다.
