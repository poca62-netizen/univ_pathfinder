# 성적·생기부 기반 수도권 대학 후보

## 사용

홈 → 성적·생기부 대학 후보. 상담 자료·상담 요약·생기부 컨설팅에서도 이동한다.
관심 학과·분야, 대학 개수(1~55), 교과/종합을 선택하고 목록 생성 버튼을 누른다.
등록 자료를 새로고침하거나 조건을 바꾸면 이전 결과를 지워 오래된 조건의 목록을 남기지 않는다.

## 데이터 출처

2028학년도 대학별 전형계획 자료의 구조화 데이터(application/json)만 읽었다.
HTML의 스크립트는 실행하지 않고 제작자 이름·브랜드·디자인·제작자 메타데이터는 가져오지 않는다.
서울 및 경기+인천 구역의 53개 대학과 서울교대·경인교대의 전형을 포함해 55개 대학,
중복 제거 후 1,045개 전형을 `assets/data/admissions_2028.json`에 보관한다.
수도권 대학의 의·치·한·약·수의·초등교육 구역도 해당 대학에 연결한다.

재생성: `node tools/build_admission_catalog.mjs <원본 HTML 경로>`.
원본 파일은 수정하거나 프로젝트로 복사하지 않는다. 학년도·자료 파일명·참고 상태만 출처 메타데이터로 기록한다.

대학별 공식 원문을 전수 대조한 자료가 아니다(대조 현황은 자료 출처 화면).
공식 확인 경로:

- [대입정보포털 2028 기본사항 및 전형계획 자료실](https://www.adiga.kr/uct/ces/archiveView.do?menuId=PCUCTCES1000&prtlBbsId=25989)
- [서울대학교 2028 입학전형 시행계획 공지](https://admission.snu.ac.kr/undergraduate/notice?bbsidx=168854&md=v)

위 링크 존재 확인은 55개 대학의 모든 전형을 검증했다는 의미가 아니다.

## 정렬·연결 규칙

1. 지원자격이나 합격을 확정하는 기능이 아니라 지원 검토 목록이다. 원본 확인된 내신과 상담 활용이 켜진 생기부가 모두 있어야 생성한다. 두 자료의 조회 실패는 미등록과 구분한다.
2. 관심 분야는 사용자 입력을 사용한다. 학과가 명시된 전형과 일치하면 우선한다. 생명과학을 의예과로 추정하지 않으며 의학/한의학/치의학/수의학을 구분한다.
3. 일반 전형에는 학과 미기재가 많다. 이런 대학은 후보로 표시하되 학과 운영·모집 여부를 확인 전으로 명시한다. 분야별 대학 경쟁력이나 전공 적합성 평가를 뜻하지 않는다.
4. 교과는 확인된 학기 종합 등급 존재, 종합은 관심 분야와 키워드가 일치하는 활성 생기부 근거 존재를 준비 자료 연결로 사용한다. 이 연결은 자료의 존재이며 성적 우수성·활동 품질·합격 점수가 아니다.
5. 동점은 화면에 공개한 편집 가능한 대학 우선 검토 순서, 그 다음 대학명 순이다. 기본 순서는 공인 대학 순위가 아니다.
6. 농어촌·기회균형 등 특별자격 전형은 기본 제외한다. 포함을 선택해도 자격 충족으로 표시하지 않는다. 추천 필요 여부와 지원자격은 원문으로 제공한다. 해당 필터는 명칭 키워드 기반이므로 최종 자격 확인을 대체하지 않는다.
7. 대학은 중복 없이 선택한 수만큼 표시한다. 부족하면 실제 개수와 부족 안내를 표시하며 가상 대학으로 채우지 않는다. 후보별 전체 교과·종합 전형은 펼쳐볼 수 있다.

## 판정 범위

성적 수치에 따른 대학별 합격선 비교·상향/적정/안정 분류는 구현하지 않았다.
첨부 자료에 입결·대학별 교과 환산식·일반 학과 목록이 없어 이를 임의 생성하지 않는다.
학생의 지원자격, 추천 가능 여부, 여대 지원자격, 수능 최저 충족 여부도 확인 전이다.
모의고사 등급을 실제 수능으로 간주하지 않는다. 논술·정시는 별도의 비교 로직이 필요해 이번 추천 대상에서 제외한다.
2028 이외 입학연도 자료는 없다. 성적은 기록별 시험·학기를 보존해 표시하고 서로 다른 체계를 합산하지 않는다.

실제 지원 가능한 대학으로 좁히려면 학과별 공식 모집요강·반영 과목과 환산식·비교 가능한 입시 결과·학생의 특별자격·추천 가능 여부를 추가 확보해야 한다.
학생 자료의 외부 AI 전송·새 DB 저장·원격 스키마 변경은 없다. 기존 가상 대학 탐색/비교 화면은 별도로 유지된다.

## 합격 가능 정도 표시

표시 체계는 약(낮음)·중(중간)·강(높음)·자료 부족이다. 현재 후보의 최종 합격 판정은 모두 자료 부족이다.
기존 준비 자료 점수나 키워드 일치를 합격 가능성으로 변환하지 않는다. 약·중·강 자동 분류를 위한
비교 가능한 전형별 입결·환산식·지원조건 검증·모델 검증은 아직 없다. 숫자 확률도 제시하지 않는다.

추가로 [공개 입결 대비 학업 비교](ADMISSION_LIKELIHOOD_RESEARCH.md)를 5개 대학·199개 모집단위에 시범 적용했다.
이 비교의 강·중·약은 최종 합격 판단과 별개이며 고1 1학기 기준의 낮은 신뢰도 근사 비교다.
학과 명시 일치 뒤에 분야가 일치하는 과거 입결 보유 대학을 우선 검토하도록 정렬하며,
비교 결과의 강·약으로 대학 목록을 정렬하지 않는다.

## 연간 평균 등록금

[한국장학재단 전국대학별평균등록금정보표준데이터](https://www.data.go.kr/data/15107738/standard.do)의
2026년 공시, 기준일 2026-05-19 자료를 사용한다. 공개 다운로드의 전체 946행 중 대학구분명 ‘대학’인
학부 행만 사용해 55개 대학·64개 본분교 기록을 연결했다. 대학원·전문대학은 제외한다.
금액은 원 단위 원자료를 보존하고 화면에서 만원 소수점 한 자리로 반올림한다.
자료 URL·제공기관·공시연도·기준일·공식 학교명·본분교 구분을 함께 제공한다.

2028 확정액, 학과별 고지액, 장학금 차감 후 실부담액을 뜻하지 않는다. 여러 본분교가 있는 대학은
단순 평균을 새로 계산하지 않고 원자료 최저~최고 범위와 개별 값을 표시한다. 서울 캠퍼스 명시 대학과
단국대 죽전은 본교 행, 한양대 ERICA는 별도의 한양대학교(ERICA) 행에 연결한다.
한국외대 글로벌의 별도 금액은 확보하지 못해 학교 본교 공시 참고액임을 카드에 명시한다.

`tools/build_tuition_catalog.mjs <공개 다운로드 JSON 경로>`로 재생성한다. 앱은 번들 자산
`assets/data/tuition.json`을 사용하며 사용 시점마다 외부 API를 호출하지 않는다.
등록금 조회에 실패해도 대학 후보는 표시하고 등록금 실패를 별도로 안내한다.
