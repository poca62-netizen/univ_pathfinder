## 2026-11-15 정시 군별 요약 행 대조 (Claude Code)

같은 17개 대학 중 12개 대학의 정시 군별 요약 행 102건을 모집단위표 합계와 대조했다(가천·가톨릭·성균관·아주·을지·덕성·동덕·한양ERICA·삼육·숙명·건국 KU일반·동국·차의과). 범위는 인원과 모집군뿐이다.

- 모두 일치하거나 실기·예체능 모집단위를 뺀 합계로 설명된다(한양ERICA 가군, 삼육 가·다군, 숙명 가·나군, 동국 나군). 근거에 산식을 남겼다.
- 숙명여대 나군의 번들 주석 "체육교육과 제외"는 실제로는 예체능 33명(체육교육 20·관현악 5·작곡 8)을 뺀 값이다.
- **확인 필요 1건:** 동국대 수능(일반전형) 가군은 원문 332명, 번들 322명이다. 차이 10명이 체육교육과인지 영화영상학과(각 10명)인지 원문만으로 정할 수 없어 수정하지 않고 "불일치 확인 필요"로 기록했다.
- 동국대 기초생활수급자 나군 합계 22명은 앞서 나군으로 정정한 약학과 2명을 포함한다. 정정의 추가 근거다.
- 이어서 이화여대 19, 중앙대 10, 한양대(서울) 11, 인하대 6, 건국대 정원 외 8건을 대조해 17개 대학의 정시 요약 152건을 모두 기록했다.
- 건국대 정원 외는 PDF 글자 좌표로 모집군·전형 열을 판별해 군별 합산했다. 같은 방식으로 계산한 KU일반(499·335·226)과 실기(32·146·69)가 원문 본문 명시값과 같아 방법을 검증했다.
- **확인 필요(수정하지 않음):** 중앙대 수능89 가·나·다(원문 합계 1,459 vs 번들 1,358), 한양대 정시 일반 나군(원문 397, 실기 제외 376 vs 번들 367), 인하대 정시 일반 다군(원문 279, 실기 제외 227 vs 번들 195), 동국대 정시 일반 가군(원문 332 vs 번들 322). 중앙대 수능67·계약정원은 합계만 일치하고 군별 분배는 미확인이다.
- 이어서 나머지 대학의 정시 행 166건을 대조했다(30개 대학 PDF 추가 확보, 서울교대·경인교대는 재게시본을 찾지 못함). 원문에 군별 인원이 명시된 경우(서강·신한·대진·한국항공·인천 등)와 합계 줄에서 확인되는 경우는 일치, 합계만 맞고 군별 분배를 못 본 경우와 이월 전형의 규정 문구를 못 찾은 경우는 "부분 일치"로 기록했다.
- 추가 "확인 필요": 성신여대 일반학생 가·나군(원문 411·274, 번들 307·232), 경기대 일반학생Ⅰ 나군(원문 157, 번들 97). 번들 값은 유지했다.
- 수시 전형 요약 행은 텍스트 자동 대조로 245건을 기록했다. 규칙: 전형 핵심 이름과 인원이 같은 줄에 있거나, 핵심 이름이 들어간 제목 아래 12줄 안에 "모집인원 N명"이 있으면 근거 줄을 인용해 기록한다. 무작위 표본 25건을 사람이 확인해 모두 맞았다. 전년 대비 비교 줄(증가·감소·확대·동일·화살표 또는 숫자 3개 이상)에서 찾은 103건은 학년도 열을 구분하지 못하므로 "부분 일치"로 낮췄다.
- 근거를 찾지 못한 184건(이미지형·복잡한 표의 수시 행, 교대 18건 포함)은 대조 전 상태로 남겼다.
- 남은 정시 행 19건: 한국외대(서울·글로벌) 일반 6, 국민대 3, 서울여대 3, 한경대 2(텍스트에서 수치를 찾지 못함), 서울교대 3, 경인교대 2(원문 미확보).
