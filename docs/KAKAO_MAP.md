# 카카오 직선거리 지도

2026-11-05 구현. 홈의 **출발지·대학 지도**, 또는 대학 비교의 **선택 대학 직선거리 지도**로 진입한다.

## 사용

1. 대학 탐색·후보에서 체크한 대학을 지도 목적지로 가져온다. 기관명과 정확히 일치하는 유일한 대학 위치만 자동 적용한다. 캠퍼스가 모호하거나 검색하지 못한 대학은 **위치 선택·변경**에서 주소·캠퍼스를 확인하고 선택한다.
2. **출발지 기관명 또는 주소**에 기관명, 도로명 주소 또는 지번 주소를 입력하고 검색한다. 결과 목록의 장소명과 주소를 확인해 적용한다. 입력 중인 검색어와 이미 적용된 출발지는 구분한다.
3. **목적지 대학·기관명 또는 주소**에서 선택 목록에 없는 대학, 도서관 등의 기관 또는 주소를 추가할 수 있다. 대학 위치 수정 중에는 해당 대학 위치로 적용하며, **일반 목적지 추가로 전환**으로 별도 목적지를 추가한다.
4. 초록은 출발지, 파랑은 일반 목적지와 직선, 주황은 위치가 확인된 목적지 중 최단 직선이다. 목적지 목록에도 거리와 최단 표시를 제공한다. 1m 이내 차이는 공동 최단이며 화면 표시로 반올림하기 전 거리로 판단한다.

출발지 변경·삭제와 목적지 추가·삭제 시 선과 최단거리를 다시 계산한다. 대학 체크를 해제하면 해당 대학은 지도에서도 제외한다. 직접 추가한 목적지는 별도 삭제할 수 있다. 추가 목적지는 최대 10개이며 선택 대학 최대 10개와 함께 표시한다. 중복 좌표의 추가 목적지는 차단한다.

직선거리는 지구 구면 거리 계산이며 자동차·도보·대중교통의 최단 경로나 소요시간이 아니다. 위치 미확인 대학은 지도와 최단거리 비교에서 제외하고 미확인 상태를 안내한다. 명칭만으로 정확한 학과 건물·정문·캠퍼스까지 확정하지 않는다.

## 설정·실행

기존 Git 제외 파일 `.env.dev.json`의 `KAKAO_JAVASCRIPT_KEY`를 Dart 빌드 설정으로 읽는다. 키 값은 HTML이나 저장소에 복사하지 않는다. 웹 SDK와 services 라이브러리로 지도·검색을 모두 처리하므로 `KAKAO_REST_API_KEY`는 이 기능에서 사용하지 않는다.

카카오 Developers에서 해당 JavaScript 키의 허용 웹 도메인에 **http://localhost:8080**을 등록한다. `run_app.bat`은 이 주소로 실행하도록 고정했다.

```powershell
flutter run -d chrome --web-hostname=localhost --web-port=8080 --dart-define-from-file=.env.dev.json
```

배포 시에는 실제 배포 도메인도 카카오에 등록하고 JavaScript 키 설정을 포함해 웹 빌드한다. 지도는 현재 Flutter 웹 버전에서 지원하며 다른 플랫폼에는 안내를 표시한다.

## 검색·오류 처리

- `Places.keywordSearch`와 `Geocoder.addressSearch`를 함께 요청하고 좌표가 같은 결과를 합친다. 키워드 최대 15개·주소 최대 10개 결과를 제공하므로 지역·캠퍼스명을 함께 입력해 범위를 좁힌다.
- 검색 결과 없음, 검색 실패, 키 누락, SDK 연결 실패를 처리한다. 검색어 변경 뒤 도착하는 과거 응답을 무시한다. 대학 자동 위치가 실패해도 직접 검색·재시도할 수 있다.
- SDK 로드 실패 후 지도 재연결 버튼을 제공한다. 실제 연결 초기에 관찰된 401은 개발 도메인 불일치였으며 사용자 도메인 등록 후 정상 연결을 확인했다.
- 검색어는 카카오에 전송한다. 선택한 출발지, 추가 목적지, 대학 위치는 앱 실행 중 메모리에 유지하며 로그아웃하면 지워진다. 지도 라벨은 HTML 삽입 없이 텍스트로 구성한다.

## 목적지별 실제 길찾기 연결 (2026-11-05)

목적지 목록에서 **카카오 길찾기 이동수단**(대중교통·자동차·도보·자전거)을 선택하고 대학/기관별 **카카오 길찾기**를 누른다. 적용된 출발지와 해당 목적지의 이름·위도·경도를 카카오 공식 길찾기 URL로 전달해 새 창을 연다. 출발지 또는 목적지 위치가 없으면 비활성화한다. 새 창이 차단되면 링크 복사를 제공한다. 경로·교통상황·운행시간은 카카오맵에서 확인하며 이 앱이 직접 수집하거나 자동 비교하지 않는다.

**직선거리 가까운 순**은 기본으로 켜져 있으며 미확인 목적지는 뒤에 표시한다. 출발지가 없으면 기존 선택 순서를 유지한다. 이 순서는 자동차·대중교통 이동시간 순위가 아니다. 카카오 길찾기 링크에는 사용자가 선택한 출발지와 목적지 위치가 포함된다.

## 지도 영역의 대학 표시 (2026-11-16)

지도 위 **대학** 칩을 켜면 카카오 지도 JavaScript SDK `services.Places(map).categorySearch('SC4', …, {useMapBounds: true})`로 현재 지도 영역의 학교를 찾고, 카테고리가 `대학교`·`전문대학`으로 끝나는 장소만 보라색 표시로 그린다. 같은 대학의 하위 장소(이름이 다른 결과 이름 + 공백으로 시작)는 뺀다. 카카오는 한 검색에 최대 3쪽(45곳)을 주므로 45곳에 닿으면 확대를 안내한다. 지도 레벨 9보다 넓으면 검색하지 않고 확대를 안내한다.

사용자가 지도를 끌거나 확대·축소하면(앱이 출발지·목적지에 맞춰 옮긴 경우 제외) 지도 위에 **현 지도에서 검색** 버튼이 나오고, 누르면 그 영역을 다시 찾는다. 결과는 지도 아래 목록에도 나오며 목적지 추가, 앱 대학 목록과 이름이 정확히 같은 대학은 관심 대학 추가를 제공한다. 같은 JavaScript 키와 SDK를 쓰므로 새 키·서버 비용은 없다. 검색 범위(지도 영역)는 카카오로 전달되며 앱에 저장하지 않는다.

## 자동차 통학시간 비교

로그인 후 지도에서 출발지와 목적지 위치를 적용하고 **자동차 통학시간 비교**를 누른다. 카카오모빌리티의 조회 시점 예상 소요시간과 도로 이동거리를 표시한다. 결과는 소요시간이 짧은 순이며 조회에 실패한 목적지는 뒤에 표시한다. 앱에서 비교하는 이동수단은 자동차다.

앱에 연결된 `univ-pathfinder-kr` 프로젝트에 `commute-times`와 `KAKAO_REST_API_KEY` 서버 시크릿을 등록했다(2026-11-06). CLI에서 이 프로젝트는 `production`으로 표시된다. 인증 없는 요청의 401 차단과 임시 인증 계정으로 공개 캠퍼스 두 곳의 거리·시간 반환을 확인했다. 함수는 Supabase 사용자 세션을 확인한 뒤 좌표만 카카오모빌리티에 전달한다. 웹 지도는 JavaScript 키를 사용한다.

다른 프로젝트에 연결할 때는 해당 프로젝트의 서버 시크릿을 등록하고 함수를 배포한다.

```powershell
supabase functions deploy commute-times --project-ref PROJECT_REF --no-verify-jwt
```
