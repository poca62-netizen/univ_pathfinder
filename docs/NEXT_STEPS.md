# 다음 개발 순서

2026-11-06 PRD 대조 결과, P1의 공식 원문 연결을 먼저 보완했다. 서울대·연세대(서울)·고려대(서울)·경희대·숭실대의 2028학년도 공식 시행계획 링크와 확인일을 탐색·비교·대학 후보에 표시한다. 비교 화면에서 당시 대학·조건·전형·등록금·출처 메모를 계정별 현재 브라우저에 최근 10건 저장해 다시 읽을 수 있다. 학과별 공식 등록금, 최종 모집요강과 일정 대조, 관리자 수집·갱신, 계정 데이터 삭제, 비교 이력의 기기 간 동기화는 후속 항목이다.

기준일: 2026-11-05

1. 완료: 확인된 내신 DB 저장 → 저장 목록 조회 → 학년·학기 필터 → 상세 항목 확인 → 개별 삭제. 가상 성적으로 실제 개발 DB 저장·재조회·삭제 검증.
2. 완료: 성적 기록에 자료 연도·중간/기말/학기 종합 구분·원본 대조 확인 시각을 추가하는 DB 마이그레이션. 기존 기록은 정보 미상으로 유지하고 임의 추정하지 않는다. 업로드 선택값 → 저장 → 재조회 → 화면 필터까지 연결한다.
3. 완료: 저장된 성적 수정과 변경 후 재조회. 상담 자료 화면에서 저장된 내신을 DB 기준으로 복원하고 해당 시험 목록으로 이동한다. 현재 실행 중 파일 정보 목록과 저장된 성적 목록은 별개다.
4. 완료: 모의고사 전용 모델·DB·검토 표·일괄 저장·조회·수정·삭제. 지원하는 표에서 영역별 원점수·표준점수·백분위·등급을 채우고 누락 등급을 로컬 보완한다. 원본 대조 후 선택한 영역을 한 요청으로 저장하며 재시도는 같은 ID를 유지한다. 내신 테이블에 혼합하지 않는다. 다른 모의고사 양식 확장은 후속이다.
5. 완료: 생활기록부 전용 모델·DB·검토 입력·저장·조회·수정·삭제. 활동 원문·출처 위치 필수, 관심 진로 메모 별도, 원본 대조 후 저장. 추출 원문 연결 및 연도·학년 필터. 자동 근거 분류는 후속이다.
6. 완료: 현재 사용자 DB 자료로 상담 요약 조회. 원본 대조 확인된 내신, 저장된 모의고사 지표, 생활기록부 원문·출처를 분리 표시한다. 관심 분야는 사용자 진로 메모 기준으로 활동에 연결하며 자동 적성 판정은 하지 않는다. 조회 실패·자료 없음·미확인 내신을 구분한다.
