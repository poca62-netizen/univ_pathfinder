# 2028 합격 가능 정도 추정 방법 조사

조사일: 2026-11-04. 최초 조사 후 사용자 요청으로 아래 ‘시범 구현’의 학업 비교만 앱에 반영했다. 본문의 확률·최종 판단 설계 전체가 구현된 것은 아니다.

## 결론

교과전형부터 ‘약·중·강(참고 추정)’을 시범 구현할 수 있다. 대학·캠퍼스·학과·전형별
과거 결과와 2028 선발 방식, 학생 자료 및 경험적 5/9등급 분포를 연결해야 한다.
실제 지원자와 합불 결과가 없는 현재 상태에서 검증된 합격확률을 산출할 수는 없다.
현재 코드의 준비 자료 존재 점수를 확률로 재사용해서는 안 된다.

   - 과거 어디가 입결을 연결한 사례가 있으나 수능 최저·서류·면접 차이를 고려하도록 명시한다.
   - 1학기 표본을 2학년 3개 학기 전체나 선택과목까지 일률 적용하면 안 된다.

     PDF 직접 열기는 타임아웃이었다. 2028 지원에는 해당 학년도 공식 기준을 별도 적용해야 한다.
4. [대입정보포털 공식 전형·결과 페이지 예시](https://m.adiga.kr/mob/ucp/uvt/uni/univDetailSelection.do?menuId=MOUVTINF1001&searchSyr=2026&unvCd=0000023)

## 필요한 데이터와 처리 순서

1. 대학·캠퍼스·학과·전형·모집연도 식별자를 정확하게 연결한다. 동일 대학 전체에 한 등급을 붙이지 않는다.
2. 졸업연도·고교유형·추천·특별자격·필수 이수과목을 먼저 확인한다.
   현재 요건 미충족과 미래 요건 미확인을 구분한다. 미래 수능 최저는 모의고사로 충족 확정하지 않는다.
3. 학생의 학기 종합 성적만 대학별 반영 교과·학점·학년 가중치로 계산한다.
   중간·기말·학기 종합을 중복 합산하지 않는다. 등급 없는 과목은 해당 대학의 공식 반영 규칙을 적용한다.
4. 대학별 최근 2~3개년 50/70% cut, 모집인원, 경쟁률, 충원, 산출 교과와 산식을 수집한다.
   누락·비공개·소수 모집은 0으로 처리하지 않는다. 신설·개편·전형 방식 변경에는 비교 불가 표시를 붙인다.
5. 5등급 성적과 과거 9등급 결과의 비교는 동일 반영 과목·학기 조건의 실측 누적분포를 우선한다.
   단순 비례 환산이나 단일 과목의 등급 구간을 전체 평균 분포로 대체하지 않는다.
   조건이 맞는 최신 자료가 없으면 판정을 보류한다. 환산값은 오차가 있는 구간으로 취급한다.
6. 대학별 2028 산식을 계산하는 경로와 과거 집단의 누적분포를 비교하는 경로를 구분한다.
   과거 산식으로 계산한 환산점수를 2028 점수와 직접 비교하지 않는다.

## 약·중·강 규칙 제안 — 공식 대학 기준 아님

교과 중심의 비교 가능한 전형에 한정한 시범 규칙이다. 판정 경계·오차폭은 실제 비교 검증으로 정해야 한다.

- 강: 보수적인 성적 추정에서도 호환되는 여러 연도의 50% 수준보다 유리하고 지원요건의 불확실성이 적음.
- 중: 성적 추정구간이 과거 50~70% 수준 또는 연도별 변동구간과 겹쳐 판단이 혼재함.
- 약: 낙관적인 추정에서도 여러 연도 70% 수준보다 불리함. 70%는 최저합격선이 아니므로 불합격 확정을 뜻하지 않음.
- 자료 부족: 학과/전형 연결·성적 반영조건·분포·입결·요건의 핵심 자료가 없거나 비교 조건이 달라짐.

세 구간에 억지로 배분하지 않는다. 성적 비교가 유리하더라도 필수 추천·최저·정성요소가 미확인이면
최종 강을 확정하지 않고 ‘학업 비교 강 / 최저 미확인 / 종합 판단 보류’처럼 조건을 분리한다.
추정 결과와 근거 신뢰도는 별개로 표시한다. 2028 제도 전환의 불확실성을 감추지 않는다.

학종에는 이 규칙을 그대로 쓰지 않는다. 공식 평가항목별 원문과 출처를 연결하고 상담자 검토를 받는다.
AI는 이수·탐구·성장·협업 사례를 정리하고 누락을 확인하는 데 사용하며, 합격 표본 학습과 검증 없이
생기부 길이·키워드 횟수·주관적 점수만으로 약/중/강을 확정하지 않는다.

## 시범 적용과 검증

- 처음에는 관심 분야의 수도권 5~10개 대학과 명시된 학과·교과전형에 한정한다.
- 과거 동일 체계에서 이전 연도만으로 다음 연도 결과를 비교하고, 누락·개편·캠퍼스 혼동을 점검한다.
  이 검증이 2028 제도 전환의 예측 정확도를 입증하는 것은 아니다.
- 교사/상담자의 평가와 비교해 오판·근거 누락·강의 과다 부여를 조사한다.
- 실제 확률은 동의·적법한 수집과 이용범위가 확보된 지원자·합격/불합격 자료가 생겼을 때 검토한다.
  합격자 또는 최종등록자 분포만으로 지원자의 합격확률을 학습할 수는 없다.
  연도 분리 검증·확률 보정·오차 측정이 필요하다.
- 결과 카드에는 대학/학과/전형, 약·중·강(추정), 근거 신뢰도, 학업 비교 범위,
  생기부 검토 상태, 최저/추천 조건, 출처와 기준연도를 함께 표시한다.

## 시범 구현 범위

2026-11-04 확장: 5개 대학의 199개 모집단위, 2024·2025 결과 398행을 공식 어디가 원문에서 수집했다. 결과연도·등급 열·캠퍼스를 확인하며 한 해만 있는 학과는 비교에 넣지 않는다. `node tools/collect_admission_results.mjs --write`로 다시 수집하며 공개 원문 캐시는 git에서 제외한다. 과거 결과가 없는 2027 조회 페이지는 출처 목록에서 제외했다. 기존 8개 수동 검증 기준값도 재수집 시 일치 여부를 검사한다.

누적 선택: [부산교육청 2026-09-04 공식 자료](https://www.pen.go.kr/main/na/ntt/selectNttInfo.do?bbsId=2286&mi=30397&nttSn=1179461)의 첨부 PDF 1쪽 실측 대응표를 추가했다. 미래 고3 예상 음영값은 제외한다. 2025 고1 두 학기와 2026 고2 1학기 석차등급 과목을 모두 등록했다고 사용자가 확인한 경우에만 누적 학점평균을 비교한다. 학기마다 최소 6개 기록, 유효 등급·학점, 중복 여부를 검사하지만 완전성은 원본 대조가 필요하다. 과목 누락을 자동으로 발견하는 기능은 아니다. 표의 두 노드로 감싸며 보간·외삽하지 않는다. `node tools/build_cumulative_bridge.mjs`로 표를 재생성한다.

입결 지표 혼재·중앙값/70%컷 역전·모집인원 3명 이하는 자료가 있어도 비교를 보류한다. 지원자격·학교장 추천·수능 최저 준비는 별도 본인 확인 항목이며 현재 화면에서만 유지된다. 실제 자격 판정·모의고사 기반 최저 자동 계산·DB 저장은 미구현이다.

- 2024·2025 공식 어디가 결과를 확인한 홍익대(서울)·광운대·국민대·숭실대·경희대의 199개 모집단위. 학과별 수록 범위는 번들의 benchmarks 목록을 기준으로 한다.
- 홍익대의 ‘50% cut’ 별표는 실제 평균값이므로 등록자 평균으로 저장한다. 나머지 4개 대학은 50%컷으로 구분한다. 페이지의 조회학년도와 실제 결과학년도가 1년 다른 것도 구분한다.
- 국민대·숭실대는 과거 전형명과 현재 참고파일의 전형명이 달라 명시적으로 연결하고 변경 사실을 표시한다. 동일 전형·동일 학과가 2028에도 유지된다는 판정이 아니다. 국민대는 현재 졸업예정자 대상 Ⅰ전형만 연결하고 Ⅱ전형에 복제하지 않는다.
- 기본 분포는 2025 고1 1학기 6개 공통과목이다. 정확히 이 기간의 확인된 학기 종합 기록과 유효한 1~5등급·학점이 있어야 한다. 다른 학기·중간·기말·중복·미확인·공란을 대입하지 않는다.
- 단순평균과 학점평균을 각각 계산하고 두 값의 범위를 감싸는 공개표 노드의 9등급 대응값을 취한다. 이것은 앱의 보수적인 근사 비교 방법이며 통계적 신뢰구간이나 공식 대학 환산식이 아니다. 표의 단순평균 표시와 학점 반영 누적분포 차이도 화면에 명시한다.
- 대응 범위 전체가 두 해 모두의 등록자 평균/50%컷보다 유리하면 학업 비교 ‘강’, 두 해 모든 70%컷보다 불리하면 ‘약’, 그 사이 겹침·혼재는 ‘중’. 핵심 자료 누락·지표 역전·연도 부족·비정상 비교표는 자료 부족.
- 현재 신뢰도는 모두 낮음이다. 실제 합격 가능 정도는 여전히 자료 부족이다. 학종에 이 비교를 적용하지 않고 준비 자료 존재 점수를 확률로 바꾸지 않는다. 연도 분리 예측 검증·실제 합불 검증은 아직 수행하지 않았다.
- 추천 대학 개수는 유지한다. 2028 파일의 학과 일치 다음에 분야가 일치하는 과거 입결 보유 대학을 우선하며 강·약으로 순서를 조작하지 않는다.
- 출처는 `assets/data/admission_comparison.json`에 대학별로 저장하고 화면의 계산·입결·출처 확인에서 제공한다.
