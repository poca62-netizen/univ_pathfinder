# AI·대학 데이터 연결 계획

기준일: 2026-11-01. 사용자는 무료 API를 선호한다. 이 문서는 조사·설계이며 연결 완료 보고가 아니다.

후속 구현: 생성형 AI와 별개로 **PDF.js + Tesseract.js 로컬 파일 추출·내신 DB 저장**을 연결했다. 아래 표의 PaddleOCR·Ollama는 여전히 미설치 후보이며, 실제 채택된 브라우저 OCR 경로는 [로컬 인식 안내](LOCAL_OCR_IMPORT.md)에 기록했다.

## 비용과 제공자 선택

| 선택지 | 용도 | 상태·한계 |
| --- | --- | --- |
| API 없는 체험 모드 | 화면·검증·선택 흐름 개발 | 이번에 구현. AI 비용·키 없이 사용. 실제 추출·추천은 하지 않음 |
| Gemini API 무료 할당량 | 성인 개발자가 가상 자료로 품질 시험 | PDF·구조화 출력 지원. 학생용 운영 API로 확정하지 않음 |
| 자체 실행 OCR·로컬 모델 | 외부 호출료를 줄이는 개발·운영 후보 | PaddleOCR와 Ollama 로컬 전용 실행 검토. 설치·실행하지 않음. PC 성능·처리 속도·모델별 라이선스·운영 비용 별도 검증 |
| 학생용 서비스를 허용하는 관리형 API | 실제 다중 사용자 서비스 | 제공자·약관·개인정보 처리·비용 상한 검토 후 선택. 무료 운영을 보장하지 않음 |

Gemini 무료 추천은 조건부다. [공식 추가 약관](https://ai.google.dev/gemini-api/terms)은 18세 미만을 대상으로 하거나 이들이 접근할 가능성이 있는 API 클라이언트에서의 사용을 제한한다. 무료 서비스에는 개인·민감·기밀 정보를 제출하지 말라는 조건과 제품 개선을 위한 입력·출력 이용 조건이 있다. 유료 결제 전환만으로 연령 제한이 사라진다고 해석하지 않는다. 따라서 고등학생용 앱에 그대로 채택하지 않는다.

조사 근거:

- [Gemini 요금·무료 등급](https://ai.google.dev/gemini-api/docs/pricing)
- [Gemini PDF 처리](https://ai.google.dev/gemini-api/docs/document-processing)
- [구조화 출력](https://ai.google.dev/gemini-api/docs/structured-output)
- [PaddleOCR 공식 저장소](https://github.com/PaddlePaddle/PaddleOCR): 한국어를 포함한 다국어 OCR, Apache 2.0 코드. 채택할 모델의 조건도 별도 확인한다.
- [Ollama 공식 FAQ](https://github.com/ollama/ollama/blob/main/docs/faq.mdx): 로컬 전용 실행 가능. 실제 모델과 OCR 서버·원본 처리는 별도 구현해야 한다.

## 자료 분석 계약

- 공통: 자료 종류, 학년, 성적/기록 연도, 학기 또는 모의고사 시행 월, 원본 페이지/표 위치, 확인 상태.
- 내신: 중간·기말·학기 종합 기록을 별도 구분. 원점수·평균·이수단위·성취도·석차등급·등급 체계를 원본대로 추출한다. 기존 DB는 5등급 한정이므로 다른 체계는 현 스키마에 억지 저장하지 않는다.
- 모의고사: 시행 기관·월, 영역·선택 과목, 원점수·표준점수·백분위·등급을 분리한다. 내신과 합산 평균하지 않는다.
- 생활기록부: 진로·세특·동아리·탐구 활동 등의 근거와 페이지 위치를 보존한다. 원문에 없는 활동·성과를 만들지 않는다.
- 모든 결과는 사용자 확인 전 상담 확정 근거로 사용하지 않는다. 자료 불일치·누락은 별도 표시한다.

## 분야별 상담과 5~10개 대학

1. 확인된 성적·모의고사·활동 근거를 분야별로 정리한다.
2. 관심 분야 및 희망 학과와 공식 전형 요건을 비교한다. 근거·부족한 자료를 함께 표시하고 합격 확률을 임의 생성하지 않는다.
3. 후보 중 5~10개 대학을 선택한다. 현재 가상 후보 목록은 이 상담·추천 단계의 결과가 아니다.
4. 실제 데이터는 대학 ID·캠퍼스 ID·학과 ID로 구분한다. 각 학과의 모집 학년도·전형·모집 인원·자격·평가·일정·원문 URL·확인일을 기록한다.
5. 학비는 학과·기준연도·학기/연간·금액·출처로 관리한다. 장학금·기숙사비·생활비는 등록금과 분리한다.
6. 주소→좌표와 좌표→캠퍼스 경로는 지도 서비스로 처리한다. 교통수단·조회 시각·거리·시간을 표시한다. 현재 직선거리 계산은 경로 계산을 대체하지 않는다.

## 실제 연결 전 필요한 작업

- 제공자 확정과 서버 비밀키 설정. 키는 Flutter·Git·채팅에 넣지 않는다.
- 사용자 인증 검증·업로드 제한·호출량 제한·시간 초과·중복 요청 처리.
- 원본 서버 보관 여부와 공급자 보관 조건을 구분하고 처리·삭제 동작 검증.
- 현재 학년/학기 성적 DB와 신규 문서·모의고사·생기부 구조를 분리하는 마이그레이션 검토.
- 공식 대학 데이터 출처 확보. 현재의 12개 가상 대학에는 실제 모집정보·좌표를 채우지 않았다.
- 가상 성적표·가상 생기부로 OCR 정확도와 사람 검토 흐름을 먼저 검증.

위 작업은 이번 변경에서 배포·설치·원격 DB 변경하지 않았다.
