# NVIDIA OCR v2 연결

2026-11-01 작성. 이미지 인식 제공자는 NVIDIA Nemotron OCR v2로 선택했다.

## 2026-11-02 수정 및 한계

결과 화면의 **원본 보기**에서 사진을 확대·이동하며 입력값과 대조할 수 있다. 원본을 닫아도 편집값은 유지한다. 결과 엔진명에 전체 이미지/표 확대 사용 여부를 표시하고 확대 재인식 실패도 안내한다. 이 기능은 원본 대조를 돕는 것으로, 기존에 확인된 과목명·평균 오인식이 모두 해결됐다는 의미는 아니다.

- 내신 등록은 학년 → 학기 → 시험 구분(중간/기말/학기 종합) 순서로 바꿨다. 상담 자료 목록은 내신 성적표·모의고사·생활기록부 세 종류로 진입한다.
- NVIDIA의 여러 줄·합쳐진 머리글을 좌표로 재구성한다. 확인된 표 머리글의 `수험수/수형수`, `가강자수`, `함계` 오인식만 문맥에 맞게 처리한다. 성적 수치 자체는 교정하거나 추정하지 않는다.
- 브라우저에서 원본 내신 표 영역을 잘라 확대하고 NVIDIA로 추가 인식한다. 추가 요청은 최대 한 번이다. 전체와 확대 결과의 과목·학점·점수·평균이 다르면 원본 대조 경고를 표시한다. 취소 후 도착한 결과는 적용하지 않는다.
- 사용자 지정 `2-1-1.jpg`의 기존 원본 응답은 7과목의 과목명·학점·원점수·평균 대조를 통과했다. 이후 모든 변형 이미지의 정확도를 보장하는 결과는 아니다.
- 사용자 지정 `2-2-1.jpg`는 확대 응답에서 6과목을 추출했으나, 원본 대조에서 한 과목명의 로마숫자와 마지막 과목 평균이 달라 **완전 일치 검증에 실패했다**. 사용자가 직접 확인·수정해야 한다. 제공자 재호출 시 응답이 달라질 수도 있다.
- `1-1-1.jpg`는 중간·기말·수행 합산 및 좌우로 이어진 복합 표다. 현재 자동 성적 추출을 지원하지 않으며 합산표가 개별 시험으로 저장되지 않도록 차단한다. 직접 입력이 필요하다.
- `M2-9.jpg`는 2학년 9월 모의고사로 식별했다. 학년·시행 월을 선택할 수 있고 글자 확인은 가능하나, 모의고사 전용 수치 추출·DB 저장은 아직 지원하지 않는다.
- 폴더의 나머지 모든 사진을 외부 API로 일괄 검증한 것은 아니다. 실제 응답·대조값은 Git 제외 `tools/ocr/test-output/`에만 두며 실제 성적을 DB에 저장하지 않았다.

## 현재 배포·검증 상태 (2026-11-01 갱신)

앱 환경 파일의 Supabase URL과 일치하는 한국 리전 `univ-pathfinder-kr` 프로젝트에 `NVIDIA_API_KEY`를 등록하고 `nemotron-ocr` 함수를 배포했다. 다른 프로젝트는 변경하지 않았다.

- 실제 배포 함수를 거쳐 가상 한글 성적표 PNG → 좌표 변환 → 기존 파서 → 두 과목 DB 저장 → 동일 ID로 재시도 → 두 행 재조회까지 통과했다. 점수도 가상 원본과 일치했다.
- 검증용 성적·프로필 행은 정리했다. 검증용 익명 Auth 사용자는 관리자 삭제 권한이 없어 남아 있다. 기존 사용자 세션은 사용하지 않았다.
- 로그인 없는 요청은 HTTP 401, 브라우저 OPTIONS 요청은 HTTP 200을 확인했다.
- 이 검증은 Dart 클라이언트 통합 시험이다. 브라우저에서 실제 사용자가 클릭하는 전체 흐름과 실제 학생 사진 정확도는 별도로 확인해야 한다.

재현 명령(가상 PNG가 `tools/ocr/test-output/sample.png`에 준비된 상태):

```powershell
flutter test --no-pub --dart-define=LIVE_NVIDIA=true tools/live_grade_import_test.dart
```

아래 배포 절차는 향후 재배포용이다. 최초 배포는 완료했다.

## 구현
- 로그인한 사용자의 JPG/PNG는 Supabase Edge Function `nemotron-ocr`를 통해 NVIDIA로 보낸다.
- 익명 로그인도 유효한 사용자 JWT가 필요하다. 서버에서 `/auth/v1/user`로 확인한다.
- 원본은 Storage/DB에 저장하지 않는다. NVIDIA의 처리·보관 조건은 해당 서비스 약관을 따른다.
- 5MiB, JPEG/PNG 시그니처, 인증, 타임아웃을 검사한다. 외부 응답·문서·키를 로그로 출력하지 않는다.
- 좌표와 신뢰도를 기존 표 파서로 변환한다. 사용자가 대조·수정·확인한 값만 기존 RLS가 적용된 DB에 저장한다.
- PDF와 체험 모드는 기존 로컬 인식이다. PDF를 NVIDIA에 보내는 변환 경로는 아직 없다.
- 취소는 결과 적용을 막는다. 이미 전달된 서버 요청은 최대 60초 동안 처리될 수 있다.
- 서버 공통 사용량 제한·사용자별 영구 할당량은 미구현이다. 공개 운영 전에 보완해야 한다.

## 비밀키와 배포
NVIDIA 키는 클라이언트 빌드 환경 `.env.dev.json`에서 제거하고 Git 제외 파일 `supabase/.env.local`의 `NVIDIA_API_KEY`로 분리했다. 이 파일을 Flutter의 dart-define 입력으로 사용하지 않는다.

Supabase CLI로 프로젝트 계정에 로그인한 환경에서 다음 순서로 실행한다. PROJECT_REF는 Supabase 대시보드의 프로젝트 ID로 바꾼다. 이 명령은 키 값을 터미널 인수에 포함하지 않는다.

```powershell
supabase login
supabase secrets set --env-file supabase/.env.local --project-ref PROJECT_REF
supabase functions deploy nemotron-ocr --project-ref PROJECT_REF --no-verify-jwt
```

`--no-verify-jwt`는 게이트웨이의 JWT 검사를 끄는 설정이다. 함수 자체는 모든 POST에서 사용자 토큰을 Auth 서버로 검증하며, 인증 없이 NVIDIA를 호출하지 않는다.

최초 직접 API 시험에서는 가상 한글 성적표 호출이 성공했고 모델명 `nvidia/nemotron-ocr-v2`, 20개 탐지와 한글 반환을 확인했다. 이후 서버 경유·DB 저장 검증은 위 현재 상태에 기록했다. 실제 성적표 정확도는 아직 검증하지 않았다. 기존에 키를 포함해 웹 빌드/배포했다면 NVIDIA에서 키를 교체하고 서버 Secret도 갱신한다.

## 공식 형식
- https://build.nvidia.com/nvidia/nemotron-ocr-v2
- https://docs.nvidia.com/nim/ingestion/image-ocr/latest/use-the-api.html
- https://nvidia.github.io/NeMo-Retriever/extraction/prerequisites-support-matrix/

호스팅 endpoint: `https://ai.api.nvidia.com/v1/cv/nvidia/nemotron-ocr-v2`.
요청은 `input`의 이미지 data URL과 `merge_levels: ["word"]`, 응답은 `data[].text_detections`의 텍스트·정규화 좌표·신뢰도를 사용한다. 한국어 가상 성적표의 동작은 검증했으며, 다양한 실제 서식의 정확도는 추가 검증 대상이다.

### 기말고사 석차등급 보완 (2026-11-04)

원점수·과목평균 머리글이 있는 기말 통지표도 표 구조로 복원해 여러 줄의 성취도 분포비율과 석차등급을 분리합니다. 제공된 사진의 캐시된 OCR 응답에서 일반교과 6과목 등급·학점·원점수·평균을 대조했습니다. 과목명 및 하단 일부 과목의 학점·성취도 오류는 남아 있어 원본 대조가 필요합니다. 모든 필드의 자동 인식이 완료된 상태는 아닙니다. 과목점수는 별도 원점수 열과 구분하며, 석차에서 등급을 계산하지 않습니다. 이미 DB에 저장한 기록은 자동 변경하지 않습니다.

### 내신 교과 범위 (2026-11-04)

사용자 요구에 따라 보통교과 및 전문교과만 내신 저장·분석 대상으로 삼습니다. 체육·예술과목 / 과학탐구실험, 교양교과는 구역 전체를 제외합니다. 따라서 앞 절에서 보존 대상으로 설명했던 하단 별도 표는 이제 저장 후보에 포함하지 않습니다. 기존 캐시 대조도 일반교과 6과목 기준으로 수행합니다. 통합과학은 제외 대상이 아닙니다. 기존 DB 행을 자동 삭제하지 않으며, 구역 정보가 없는 과거 기록은 이름으로 명확히 구분되는 제외 과목만 조회·분석에서 걸러냅니다.

### 모의고사 누락 등급 보완 적용 (2026-11-04)

로그인한 모의고사 이미지에서 영어·한국사 등급이 누락되면 해당 숫자 칸을 로컬 Tesseract로 추가 인식합니다. 다른 영역의 등급 열과 영역명 행을 근거로 위치를 계산하고, 여러 차례 결과가 일치하며 신뢰도 기준을 넘을 때만 입력 제안을 표시합니다. 기존에 읽힌 등급은 덮어쓰지 않습니다. 반영 버튼은 영역·등급만 채우며 다른 성적 지표는 수동 대조 입력이 필요합니다. 제공된 사진의 실제 제품 브리지 시험에서 두 등급을 복구했지만 모든 모의고사 양식에 대한 정확도 보장은 아닙니다. 새 외부 호출·DB 저장 없이 로컬에서 보완합니다. 변경 후에는 앱과 브라우저 탭을 완전히 재시작해 새 JS 모듈을 로드하세요.

### 모의고사 전체 영역 검토 표 (2026-11-04)

모의고사 파일 인식 뒤에는 단일 영역 폼 대신 전체 영역 검토 표가 열립니다. 지원하는 상단 성적표에서 원점수·표준점수·백분위·등급을 영역별로 채우고, 영어·한국사 부분 보완 등급도 표에 표시합니다. 원본에 없는 값은 빈칸을 유지합니다. 표에서 수정·선택·원본 대조 후 일괄 저장하며, 저장 실패 시 같은 화면에서 재시도하면 동일 ID를 사용합니다. 원본 보기로 사진을 확대할 수 있습니다. 제공 사진의 6개 영역은 캐시 대조를 통과했지만 모든 양식 지원을 의미하지 않습니다. 표를 구분하지 못하면 빈 표에서 직접 입력합니다.
