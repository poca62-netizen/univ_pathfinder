# 화면 구성과 검증

2026-11-04: 대학 후보 찾기 화면 및 공통 테마 개선.

- 공통 색상·타이포·입력·카드·버튼은 `lib/theme/app_theme.dart`에 모은다. 짙은 녹색 텍스트, 녹색 액션, 밝은 회색 배경, 흰색 표면을 사용한다.
- 대학 후보 화면은 최대 1240px 너비다. 1000px 이상에서 조건 입력 330px + 결과 영역을 분리하고 작은 화면은 세로로 배치한다.
- 카드의 첫 정보는 대학 이름, 학업 비교, 연간 평균 등록금이다. 학업 비교의 낮은 신뢰도와 최종 판단 미확인은 요약에도 남긴다. 계산식·과거 입결·전형 조건·출처는 펼쳐본다.
- 미지원 학과와 성적 확인 필요를 구분한다. 약/중/강은 문자와 색상을 함께 사용하며 합격 확률로 표현하지 않는다. 복수 학과는 가장 유리한 하나로 대표하지 않는다.
- 모바일 조회 후 결과 제목으로 스크롤하고, 결과의 조건 이동 버튼으로 입력 영역에 돌아간다. 조건 변경 시 이전 결과를 지우는 기존 계약은 유지한다.
- 최초 진입, 로딩, 실패, 결과 없음, 일부 자료 실패를 별도 상태로 제공한다. 실패 안내를 상세 설명 안에 숨기지 않는다.
- 홈 메뉴는 너비에 따라 2/3/4열이다. 버튼·카드의 실제 동작은 기존 경로를 사용한다.

## 시각 검증

Windows에서 `flutter test --no-pub tools/preview_candidates_test.dart --update-goldens`를 실행한다.
가상 성적과 번들 데이터로 데스크톱·모바일·140% 글자 화면을 렌더링하며 결과는 Git 제외된
`tools/ocr/test-output/design/`에 생성한다. 한글/아이콘 미리보기 글꼴은 Windows/로컬 Flutter SDK에서 로드하며 앱에 복제하지 않는다.
실제 학생 성적이나 로그인 정보는 미리보기에 사용하지 않는다. 위젯 렌더링 검증이며 실제 로그인 브라우저 클릭 검증을 뜻하지 않는다.
