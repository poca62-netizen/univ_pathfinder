# univ_pathfinder

고등학생의 내신 중간·기말 성적표, 모의고사, 생활기록부를 바탕으로 분야별 대학·학과 상담을 제공하고, 관심 대학 5~10개의 모집정보·학비·집에서의 거리를 비교하는 Flutter 앱을 개발합니다.

## 현재 개발 상태 (2026-11-05)

- 닉네임·숫자 4자리 비밀번호 인증·중복 닉네임 차단·내신 직접 입력/조회. 확인한 파일 추출값은 연도·학년·학기·시험 구분·원본 대조 확인 시각과 함께 저장합니다. 저장 목록에서 기간별 필터, 개별 수정·삭제를 지원합니다. 수정 후 DB를 재조회하며, 과거 원본 대조 확인 표시는 초기화합니다.
- 자료 종류·학년·연도·학기/모의고사 월 구분 및 실행 중 자료 목록 관리.
- 수도권 실제 대학 55곳의 전형계획 검색, 대학명·학과명·전형명 및 전형 유형 필터, 최대 10개 선택과 모집정보·공식 연간 평균 등록금 비교. 관심 대학 설정에도 같은 선택을 표시합니다. 로그인 사용자는 **관심 대학 목록 저장**으로 현재 계정의 브라우저·기기에 저장하고 다음 탐색·비교·설정 진입 시 복원합니다. 기기 간 동기화는 없으며 브라우저 데이터 삭제 시 사라집니다.
- 사용자 제공 2028 전형계획을 참고한 수도권 대학 후보. 관심 분야와 개수를 선택하고 전형 원문·등록 자료 연결을 확인합니다. 대학별 합격선 판정은 제공하지 않습니다.
- 2028 전형계획 정리본의 모집정보 원문과 2026 공식 연간 평균 등록금·출처 표시. 학과별 확정 등록금과 최종 모집요강 전수 검증은 후속입니다.
- 카카오 지도에서 기관명·도로명/지번 주소로 출발지와 목적지 검색, 선택 대학과 직선 연결, 최단 직선의 주황 강조를 제공합니다. 로그인 사용자는 카카오모빌리티 기준 자동차 통학시간·도로 거리를 비교할 수 있습니다. 대중교통 시간은 카카오맵 길찾기 링크로 확인합니다. [지도 사용·설정](docs/KAKAO_MAP.md).
- 추출 결과 초기값 표시·편집·검증·배치 저장, 가상 결과 저장 차단.
- **PDF.js + Tesseract.js 연결 완료:** 텍스트 PDF 직접 추출, 이미지·스캔 PDF의 한국어 OCR, 표 열 매핑, 원본 대조·수정 후 Supabase 내신 저장. 외부 OCR/AI API 키는 필요하지 않습니다.

- **진학 컨설팅 리포트**: 관심 분야와 저장한 내신·모의고사로 54개 대학의 2024·2025 어디가 입결과 비교해 학생부교과·종합·정시별 안정·적정·상향·어려움을 예측합니다. 카드마다 비교한 입결(학년도·지표·인원)·신뢰도·등록금을 보여 주며 합격을 보장하지 않습니다.

생성형 AI 분석·공식 모집요강/학비 자동 수집·대중교통 소요시간의 앱 내 비교는 아직 연결 전입니다. 실제 대학 후보는 사용자 제공 전형계획 정리본을 참고하며 대학별 공식 원문 전수 대조 전입니다. 상담 자료 화면의 저장된 내신은 DB에서 시험 시기별로 복원합니다. 원본 파일 정보 목록과 체험 모드 대학 선택은 앱 재시작 시 초기화됩니다. 로그인 계정의 대학 선택은 목록 저장을 누른 경우 이 브라우저·기기에서 복원합니다. 로그인한 사용자의 이미지 인식은 동의 후 Supabase 서버를 거쳐 NVIDIA로 전송합니다. 원본은 앱 DB·Storage에 보관하지 않습니다. PDF와 체험 모드는 브라우저 로컬 인식입니다.

## 앱 실행

Windows에서는 프로젝트 폴더의 **run_app.bat**을 더블클릭합니다. 개발 설정 파일이 있으면 DB 연결 모드, 없으면 체험 모드로 실행합니다. 저장한 기록은 홈 → 성적 분석에서 확인합니다.

AI·Supabase 키 없이 화면을 확인하는 무료 체험 모드:

```powershell
flutter run -d chrome --dart-define=DEMO_MODE=true
```

기존 개발 DB를 사용하는 모드:

```powershell
flutter run -d chrome --dart-define-from-file=.env.dev.json
```

`.env.dev.json`은 `SUPABASE_URL`, `SUPABASE_PUBLISHABLE_KEY`를 가진 JSON 객체로 직접 준비합니다. `.env.example`은 변수 이름 안내용이며 실행용 JSON이 아닙니다. 실제 값은 Git에 올리지 않습니다.

내신 저장: 로그인 → **상담 자료 → 내신 중간고사/기말고사 → 파일 선택 → 성적 추출 → 확인·수정 → 원본 대조 체크 → 저장**.

파일 자동 인식은 현재 웹 버전에서 지원합니다. PDF 최대 20MB·20쪽, JPG/JPEG/PNG 이미지 최대 5MB를 처리합니다. 가상 예시 버튼은 인식만 시험하고 DB 저장은 차단합니다. 모의고사는 전용 테이블에 영역별로 원점수·표준점수·백분위·1~9등급을 저장하고 조회·수정·삭제합니다. 지원하는 모의고사 표에서는 영역별 원점수·표준점수·백분위·등급을 검토 표에 채우고, 확인·수정 후 선택한 영역을 함께 저장합니다. 누락된 영어·한국사 등급은 로컬 숫자 OCR로 보완합니다. 지원하지 않는 양식과 읽지 못한 값은 원본을 보고 입력해야 합니다. 생활기록부는 지원 양식에서 학기 종합 성적·세특·활동 후보를 추출하고 원본 대조·수정 후 함께 저장합니다. 모의고사와 생활기록부 활동 근거는 전용 테이블을 사용하며, 생기부의 보통·전문교과 성적은 학기 종합 종류로 내신 테이블에 저장합니다. 생기부 근거를 바탕으로 한 AI 상담은 생기부 컨설팅에서 제공합니다(아래). 자료 연도·중간/기말/학기 종합 구분은 DB에 저장하며, 기존에 구분 없이 저장한 기록은 미상으로 표시합니다.

배포용 JS·작업자·한국어/영어 모델은 `web/vendor/ocr/`에 포함되어 있습니다. 재생성 및 세부 제한은 [로컬 파일 인식 안내](docs/LOCAL_OCR_IMPORT.md)를 참고하세요.

## 로그인

시작 화면에서 닉네임과 **숫자 4자리 비밀번호**로 로그인합니다. 처음 사용하는 닉네임은 **회원가입**에서 등록합니다. 닉네임은 중복 등록할 수 없으며 영문 대소문자는 구분하지 않습니다. 세션이 바뀌어도 같은 자격으로 로그인하면 기존 자료가 조회됩니다. 홈 상단에서 로그아웃할 수 있습니다. 비밀번호 5회 오류 시 15분 동안 로그인이 제한됩니다. 자동 비밀번호 복구는 아직 제공하지 않습니다. 설정 → **계정 삭제**에서 비밀번호를 다시 입력하면 계정과 모든 자료를 영구 삭제합니다. [인증 구조와 검증 범위](docs/NICKNAME_AUTH.md)를 참고하세요.

## 내신 저장·분석 범위

보통교과 및 전문교과만 내신으로 저장·분석합니다. 성적표의 **체육·예술과목 / 과학탐구실험**, **교양교과** 구역은 검토 과목 목록과 저장 대상에서 제외합니다. 통합과학 등 보통교과는 유지합니다. 직접 입력과 수정에서도 명확한 제외 과목명을 차단합니다. 기존 기록 중 이름으로 확인 가능한 제외 과목은 성적 분석·상담 자료·상담 요약에서 숨기며 DB 행 자체는 삭제하지 않습니다. 기존 DB에는 교과 구역 정보가 없어 과목명만으로 구역을 판단할 수 없는 과거 기록은 자동 분류하지 않습니다.

## 모의고사 사용

로그인 → 상담 자료 → **모의고사 저장·조회** → **영역 입력**에서 시험 시기와 영역별 지표를 입력하고 원본 대조 확인 후 저장합니다. 파일을 사용하면 상담 자료 → 모의고사 → 파일 인식 → **모의고사 인식 결과 검토** 표에서 영역별 값을 확인·수정 → **선택 영역 일괄 저장**으로 이어집니다. 저장한 기록은 상담 자료에서 복원되고, 전용 목록에서 연도·학년·월 필터 및 수정·삭제를 지원합니다.

표에는 국어·수학·영어·한국사·사회탐구·과학탐구 등 읽힌 영역이 행으로 표시됩니다. 원본에 없는 영어·한국사의 표준점수·백분위는 빈칸으로 유지하고 보완한 등급은 표시합니다. 영역별 선택·제외와 수치 수정, 영역 추가를 지원합니다. 원본 보기에서 사진을 확대할 수 있으며, 값을 수정하거나 선택을 바꾸면 원본 대조 확인이 해제됩니다. 저장 실패 시 입력값과 저장 ID를 유지하므로 같은 화면에서 재시도하세요. 새 화면에서 같은 파일을 다시 가져오면 별도 등록으로 처리됩니다. PDF·체험 모드의 추가 숫자 인식과 모든 모의고사 양식의 자동 매핑을 지원하는 것은 아닙니다.

## 생활기록부 사용

로그인 → 상담 자료 → **생활기록부** 파일 선택·인식 → **생기부 추출 결과 확인**에서 학기 종합 성적과 세특·활동 후보를 검토합니다. 1학년 연도를 적용하고 항목별 연도·학년·수치·문장·출처를 수정한 뒤 저장할 항목을 선택하세요. 원본 PDF를 옆에 열어 대조하고 남아 있는 이름·학교·학번 등 개인정보를 삭제한 후 확인 체크 → 선택 항목 저장으로 진행합니다. 지원하지 않는 양식은 수동 입력이 필요하며 개인정보의 완전한 자동 제거를 보장하지 않습니다.

기존 학기 종합 성적이 있는 기간은 통째로 건너뛰고, 같은 연도·학년·항목·문장의 근거도 중복 저장하지 않습니다. 기존 중간·기말 기록은 유지합니다. 체육·예술·과학탐구실험·교양의 숫자 성적은 제외하되 세특·활동은 상담 근거로 검토합니다. 전체 원문과 원본 파일은 DB에 보관하지 않습니다. **생활기록부 근거 저장·조회 → 근거 입력**의 수동 등록과 저장 목록의 연도·학년 필터·수정·삭제도 지원합니다. AI 상담은 생기부 컨설팅에서 근거를 골라 엽니다.

## 상담 요약 사용

### 성적·생기부 대학 후보

홈 → **성적·생기부 대학 후보**에서 관심 학과·분야와 보고 싶은 대학 개수(1~55)를 선택합니다. 결과 카드의 **관심 대학에 추가**로 최대 10곳을 고르고, **선택한 N개 대학 모집정보 비교**로 전형 원문·등록금을 비교할 수 있습니다. 탐색·비교·설정과 같은 선택 목록을 사용하며, **관심 대학 목록 저장**으로 현재 계정의 이 기기에 저장합니다. 후보 조건을 바꿔도 선택은 유지됩니다. 비교 화면의 **선택 대학 비교 메모 복사**는 현재 검색·전형 필터에 맞는 원문과 등록금·출처를 복사합니다. 조건에 맞는 전형이 없거나 현재 자료에 없는 선택 대학도 표시하며 학생 성적·생기부 원문은 포함하지 않습니다. 제공한 2028 전형계획 정리본의 수도권 55개 대학·1,045개 전형을 참고하며, 제작자 정보는 데이터에 포함하지 않습니다. 실제 목록은 교과·종합 전형을 대상으로 하고 특별자격 전형은 기본 제외합니다.

학과 명시·분야 일치 → 전형별 준비 자료 연결 → 편집 가능한 대학 우선 검토 순서로 정렬합니다. 원본 확인 성적과 활성 생기부가 필요하고, 부족한 후보는 가상 대학으로 채우지 않습니다. 학과 미기재·지원자격·수능 최저·합격 가능성의 미확인 상태와 전형 원문을 표시합니다. 대학별 입결·환산식이 없어 성적 수준에 따른 합격 대학 판정은 제공하지 않습니다. [데이터 출처·정렬 기준·제한](docs/UNIVERSITY_CANDIDATES_2028.md)을 참고하세요.

대학 카드에는 **과거 입결 대비 학업 비교 약·중·강**을 시범 제공합니다. 현재 홍익대(서울)·광운대·국민대·숭실대·경희대의 199개 모집단위가 대상이며, 관심 분야가 일치해야 표시됩니다. 2025년 1학년 1학기의 공통국어·공통수학·공통영어·한국사·통합사회·통합과학 6과목 학기 종합 성적이 모두 필요합니다. 중간·기말·다른 학기·중복·공란으로 대체하지 않습니다. 계산과 2024·2025 입결은 **학업 비교 계산·입결·출처 확인**에서 확인합니다. 신뢰도가 낮은 근사 비교이며 최종 합격 가능성·확률은 여전히 자료 부족입니다. [비교 방식과 제한](docs/ADMISSION_LIKELIHOOD_RESEARCH.md)을 참고하세요.

등록금은 한국장학재단 공개 자료의 **2026년 연간 평균**을 표시하고, 본분교별 차이가 있으면 범위·개별 금액·출처를 제공합니다. 2028 확정액이나 학과별 고지액은 아닙니다. **등록금 기준·출처 확인**을 펼쳐 기준일과 캠퍼스를 확인하세요.

**입결 비교를 지원하는 대학만 보기**를 켜면 관심 분야에 과거 입결이 연결된 대학만 표시합니다. 후보 카드의 첫 상태는 실제 학업 비교 강·중·약, 성적·비교 자료 확인 필요, 미지원 학과·전형을 구분합니다. 여러 학과는 가장 유리한 한 학과로 대표하지 않고 등급별 학과 수를 표시합니다. 최종 합격 판단은 펼침 안내에서 미검증 상태로 구분합니다. 이 필터는 자료 범위를 좁히며 새로운 입결이나 지원 가능 판정을 생성하지 않습니다.

### 생기부 컨설팅

대학 후보의 **수능 최저 비교할 모의고사**에서 시험을 선택하면 전형별로 **충족 수준·미달 수준·자료 부족·원문 확인 필요**를 표시합니다. 같은 시험만 사용하며 학과별 조건은 직접 선택합니다. 지원자격·추천 본인 확인은 현재 계정의 이 브라우저·기기에 저장됩니다. 실제 수능 충족이나 합격을 확정하지 않습니다. [지원 규칙과 제한](docs/CSAT_MINIMUM_COMPARISON.md).

홈 → **생기부 컨설팅**, 또는 상담 요약 → **생기부 컨설팅 시작**에서 저장된 활성 근거별 상담 질문과 다음 행동을 확인합니다. 관심 진로·상담 질문을 적고 이번 상담에서 다룰 근거를 선택한 뒤 **선택한 근거만 보기**로 모아볼 수 있습니다. **근거 원문·출처 확인**에서 원문을 대조하고, **선택 근거 상담 메모 복사**로 목표·선택 원문·출처·질문을 복사할 수 있습니다. 원문이 포함되므로 공유할 때는 내용을 확인하세요.

탐구·협업·소통·성찰 관련 원문 키워드로 질문을 구성하는 로컬 기능입니다. 이 키워드 질문은 문맥을 이해하는 AI 분석이 아니며, 강점 확정·자동 학과 추천·합격 예측은 하지 않습니다. 목표 입력은 메모에 포함되며 자동 질문 생성이나 필터에 쓰이지 않습니다. 로그인한 사용자는 **상담 준비 저장**으로 목표와 선택한 근거 ID를 계정별 현재 브라우저·기기에 저장하고 다음 진입 시 복원합니다. 다른 기기에는 동기화되지 않으며 브라우저 데이터 삭제 시 사라집니다. 체험 모드는 화면 내에서만 유지됩니다. 복원 실패 시 덮어쓰기를 막고 재시도를 제공합니다. 새로고침 시 최신 DB 자료를 다시 읽으며 상담 활용을 끈 근거는 제외합니다.

**생기부 AI 상담**: 생기부 컨설팅에서 근거를 1~6개 고르고 **선택한 근거로 AI 상담**을 누르면 상담 선생님과 대화하듯 강점·다음 탐구·기록 보완·면접 설명을 물어볼 수 있습니다. 첫 질문 전에 외부 전송 동의를 받습니다. 앱은 근거 ID만 보내고, 서버(`app-help` 함수)가 로그인 사용자 권한으로 DB에서 상담 활용이 켜진 근거 원문(근거마다 앞 700자)과 진로 메모를 읽어 Groq(`openai/gpt-oss-120b`)에 보냅니다. 내신·모의고사 성적은 보내지 않습니다. 답의 학생 관련 문장에는 [근거 n] 인용이 붙고, 서버가 고르지 않은 번호의 인용을 지웁니다. 인용이 없는 답에는 일반 조언이라는 주의가 붙습니다. AI는 합격 가능성·점수를 판단하지 않고 진학 컨설팅 리포트로 안내합니다. 대화는 저장하지 않습니다.

홈 → **상담 요약**, 또는 상담 자료 → **상담 요약 보기**에서 현재 로그인 사용자의 내신·모의고사·생활기록부 근거를 함께 조회합니다. 내신은 원본 대조 확인 시각이 있는 기록만 요약에 포함하고, 미확인 건수와 자료 부족을 표시합니다. 모의고사는 저장된 영역별 지표를 보여주되 DB에 대조 확인 시각이 없어 확인 이력을 검증할 수 없음을 표시합니다. 자료별 조회 실패는 자료 없음과 구분합니다.

관심 분야 칩은 생활기록부에 저장한 **사용자 진로 메모**입니다. 선택하면 같은 메모가 붙은 활동 원문과 출처만 표시합니다. 성적으로 적성을 판단하거나 학과를 자동 추천하지 않습니다. 기록 확인·수정 화면에서 돌아오거나 새로고침하면 DB를 다시 조회합니다. 요약은 현재 기록으로 구성하며 별도 사본을 DB에 저장하지 않습니다.

## 수능 환산 예시

대학 후보 화면에서 모의고사를 고르면 **연세대 서울 정시 수능 환산 예시**와 **서울대 정시 수능 환산 예시**를 펼쳐 볼 수 있습니다. 서울대는 1단계 등급 환산(50점)과 2단계 백분위 환산(60점, 인문·자연·약학 등 모집단위군별 반영 비율과 영어 감점)을 원문 산식대로 계산하며, 교과역량평가·면접은 합산하지 않습니다. 가톨릭대(백분위 전형, 원문에 총점 척도가 없어 100점 기준)와 인천대(1,000점, 2028 변경 영어 점수표), 상명대(원문 계산 예시와 일치 검증), 동덕여대(1,000점 + 한국사 가산), 명지대(900점), 삼육대·경기대(총점 척도 미기재로 100점 기준) 예시도 제공합니다. 고려대·성균관대·홍익대·성신여대는 원문에 표준점수 환산 방법, 대학 자체 변환점수표, 활용 지표가 명시돼 있지 않아 추가하지 않았습니다.

### 진학 컨설팅 리포트

홈 → **진학 컨설팅 리포트**에서 관심 학과·분야를 입력하고 정시 비교에 쓸 모의고사를 고른 뒤 **리포트 만들기**를 누릅니다. 원본 대조가 확인된 내신은 학기 종합 → 기말 → 중간 순으로 골라 학점가중 평균을 내고, 5등급제를 9등급 입결과 비교하기 위해 교육청 대응표로 낙관·보수 구간을 만듭니다(근사치). 수시는 50%·70% 컷 기준, 정시는 같은 총점 척도의 2028 환산식이 있으면 환산점수, 없으면 국·수·탐 평균 백분위로 비교합니다. 한 해 자료뿐이거나 모집 인원이 3명 이하, 컷이 역전된 경우, 학생부종합, 해마다 컷이 크게 움직인 경우(수시 70%컷 0.5등급 이상 등), 해마다 공개 지표가 다른 경우는 신뢰도를 낮추고 이유를 적습니다. 정시 백분위는 내 점수와 같은 공식(국·수·탐 평균)으로 계산된 해만 비교합니다. 해마다 이름이 바뀐 전형은 대학이 공개한 변경사항으로 이름만 바뀌었다고 확인한 경우만 같은 전형으로 묶습니다. 대응표와 근거는 **자료 출처**에서 볼 수 있습니다. 수시 카드에는 고른 모의고사로 본 수능 최저 판정이 함께 나오고, 미달 수준이면 경고 아이콘을 표시합니다. 최저가 인문·자연 등 계열별로 나뉘는 전형은 **계열**을 고르면 그 기준을 적용하되, 대학마다 계열 분류가 달라 "소속 계열을 원문에서 확인"하라는 안내를 붙입니다. 예외 조건이 붙은 최저는 원문 확인 필요로 둡니다. 리포트 위쪽의 **지원 조합 예시**는 수시 6장을 상향·적정·안정으로 나누고(상향 중심·균형·안정 중심 중 선택) 정시 가·나·다군에 한 곳씩 배치한 예시입니다. 어려움·판단 보류·최저 미달 수준은 넣지 않고, 같은 대학은 한 번만, 자리를 채울 후보가 없으면 빈 자리로 알립니다. **내 성적 기준**에는 관심 분야와 연결된 생기부 근거(진로 메모가 맞거나 원문에 분야 단어가 있는 확인된 근거)의 건수와 학년·영역을 보여 주고, 펼치면 근거 목록과 원문 위치를 볼 수 있습니다. 학생부종합 서류 평가는 대학별 정성 평가라 점수로 바꾸지 않습니다. 리포트를 만든 뒤 상단의 **리포트 복사**로 성적 기준·지원 조합·전형별 판정과 근거를 텍스트로 복사할 수 있습니다. 생기부 원문은 넣지 않고 건수·분포만 넣습니다. **인쇄·PDF 저장** 버튼은 같은 내용을 인쇄용 문서로 새 창에 열고 인쇄 창을 띄웁니다. 인쇄 창에서 "PDF로 저장"을 고르면 PDF가 됩니다. 팝업이 막혀 있으면 브라우저에서 이 사이트의 팝업을 허용하세요. 체험 모드에서는 저장된 성적이 없어 메뉴가 표시되지 않습니다.

홈 → **자료 출처**에서 대학 전형계획(사용자 제공 정리본과 공식 원문 대조 현황), 과거 입결(어디가·교육청 분석 자료), 등록금(한국장학재단 공공데이터), 지도·통학(카카오)의 출처와 링크를 확인할 수 있습니다. 대조 건수는 번들 데이터에서 자동으로 계산합니다.

## 카카오 직선거리 지도

홈 → **출발지·대학 지도** 또는 대학 비교 → **선택 대학 직선거리 지도**에서 사용합니다. 기관명·주소를 검색해 출발지와 추가 목적지를 선택하고, 캠퍼스가 모호한 대학은 위치 선택 버튼으로 확인하세요. 파랑은 일반 직선, 주황은 확인된 목적지 중 가장 짧은 직선이며 실제 통학 경로와 다릅니다. 개발 실행 주소는 **http://localhost:8080**으로 고정했습니다. [키·도메인 설정과 상세 범위](docs/KAKAO_MAP.md).

지도 목적지 목록에서 **직선거리 가까운 순**과 **카카오 길찾기 이동수단**을 선택할 수 있습니다. 목적지별 **카카오 길찾기**는 현재 출발지·목적지로 카카오맵 새 창을 열며, 대중교통·자동차·도보·자전거 경로와 시간은 카카오맵에서 확인합니다. 팝업이 차단되면 링크 복사를 사용하세요.

로그인 상태에서 **자동차 통학시간 비교**를 누르면 서버(`commute-times`)를 거쳐 카카오모빌리티의 조회 시점 예상 소요시간과 도로 거리를 목적지별로 비교합니다(짧은 순). 좌표만 전송하며 출발지는 저장하지 않습니다. 앱 안에서 비교하는 이동수단은 자동차뿐입니다.
