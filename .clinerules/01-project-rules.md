# Univ Pathfinder 개발 지침

## 프로젝트 목표
- 대입 수험생을 위한 AI 기반 대학 진학 정보 분석 앱을 개발한다.
- Flutter, Supabase, Kakao Maps API, AI 문서 분석 기능을 사용한다.
- 성적표 업로드, 성적 추출 및 사용자 확인, 대학별 모집요강 검색, 등록금 비교, 집에서 대학까지 이동거리 비교를 단계적으로 구현한다.

## 기존 프로젝트 보호
- nearby_school_finder 프로젝트는 절대 수정, 이동, 삭제하지 않는다.
- 기존 프로젝트의 소스나 설정을 복사해야 할 경우 사용자에게 먼저 승인을 받는다.
- 기존 Kakao API 키는 재사용할 수 있지만 키 값을 출력하거나 소스코드에 직접 삽입하지 않는다.
- 현재 작업 공간 밖의 파일을 수정하지 않는다.

## 개인정보 및 보안
- 이름, 생년월일, 학번, 학교명, 상세 집 주소를 필수로 수집하지 않는다.
- 닉네임은 화면 표시용이며 인증 수단으로 사용하지 않는다.
- 사용자 식별은 Supabase 익명 인증의 고유 ID를 사용한다.
- 성적표 업로드 전 이름, 학교, 학번 등 식별정보 제거를 안내한다.
- 원본 성적표는 기본적으로 영구 저장하지 않으며 처리 후 삭제한다.
- 성적 데이터 접근은 사용자별 RLS 정책으로 제한한다.
- AI API 비밀키는 Flutter 클라이언트에 포함하지 않고 서버 측에서 관리한다.
- API 키, 토큰, 개인정보를 로그나 GitHub에 기록하지 않는다.
- AI 추출 결과는 사용자가 확인·수정한 후 저장한다.

## 개발 절차
- 코딩 전에 PRD.md를 작성하고 사용자 승인을 받는다.
- 기능은 작은 단계로 나누어 한 번에 하나씩 구현한다.
- 각 단계마다 변경 파일, 구현 내용, 테스트 결과를 한국어로 보고한다.
- 패키지 설치, 외부 API 호출, DB 변경, 파일 삭제 전 사용자 승인을 받는다.
- 테스트 데이터는 가상 학생·가상 성적표만 사용한다.
- 성적 계산은 검증 가능한 공식으로 구현하고 AI가 임의로 수치를 추정하지 않도록 한다.
- 대학 모집요강은 공식 출처와 학년도, 확인일, 검증 상태를 함께 기록한다.
- 합격 가능성을 보장하거나 단정하지 않는다.
